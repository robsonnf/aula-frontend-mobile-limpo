Flexbox

Flexbox distribui itens em uma dimensão por vez. Hoje a turma identifica eixos antes de escolher propriedades, controla tamanho inicial e espaço livre, permite quebra sem larguras mágicas e preserva no HTML a ordem que leitura e teclado precisam seguir.

Com flex-direction: row, qual propriedade distribui espaço livre entre os itens no eixo principal?

  • align-items
  • justify-content
  • vertical-align

1. Contêiner, itens e uma dimensão

display: flex cria um contêiner flex e transforma seus filhos diretos em itens flex. Neto não vira item automaticamente. Flexbox organiza uma linha ou uma coluna; pode haver várias linhas com wrapping, mas cada linha distribui seu espaço de forma independente.

TermoPergunta
Eixo principalEm que direção os itens são colocados?
Eixo transversalQual direção cruza a principal?
justify-contentComo distribuir espaço no eixo principal?
align-itemsComo alinhar itens no eixo transversal?
gapQual intervalo deve existir entre itens ou linhas?

“Horizontal” e “vertical” são atalhos frágeis. Com flex-direction: column, o eixo principal passa a ser o de bloco; em outros modos de escrita, até a direção de row acompanha o eixo inline.

2. Alinhamento começa pela identificação do eixo

Linha

.barra {
  display: flex;
  align-items: center;
  justify-content: space-between;
}

Distribuição inline, alinhamento transversal.

Coluna

.painel {
  display: flex;
  flex-direction: column;
  justify-content: center;
  align-items: start;
}

Agora justificar atua no eixo de bloco.

align-content distribui linhas no eixo transversal e só produz efeito quando existem múltiplas linhas e espaço livre nesse eixo. Não é substituto de align-items para uma única linha.

3. Faça a navegação quebrar por conteúdo

Os links foram forçados a permanecer numa linha e transbordam no celular. Permita quebra, use gap: .75rem e faça cada item partir de 10rem, crescer e encolher. Não mude a ordem do HTML.

4. O algoritmo parte de uma base e distribui espaço

ComponentePapel
flex-basisTamanho principal inicial antes da distribuição.
flex-growFator para dividir espaço positivo disponível.
flex-shrinkFator para retirar espaço quando falta.
flexAtalho recomendado que define o trio de modo coerente.

flex: auto corresponde a 1 1 auto e conserva o tamanho inicial derivado do conteúdo ou da propriedade de tamanho. flex: 1 parte de base zero e tende a dividir o espaço igualmente, mas o mínimo intrínseco dos itens ainda pode impedir que encolham.

MDN — proporções no eixo principal

5. O mínimo automático explica muito “Flexbox quebrado”

Por padrão, um item flex com overflow não rolável usa um mínimo automático baseado no conteúdo. Uma URL longa, tabela ou controle pode impedir o item de encolher. Quando o contrato permite quebra ou recorte interno, min-inline-size: 0 libera o encolhimento no eixo inline. Não aplique cegamente: confirme qual conteúdo poderá reduzir.

.linha { display: flex; gap: 1rem; }
.conteudo { flex: 1 1 auto; min-inline-size: 0; }
.conteudo p { overflow-wrap: anywhere; }

O que flex-basis define?

  • O espaço definitivo depois de todo o algoritmo
  • O tamanho principal inicial antes de crescer ou encolher
  • A distância entre os itens

6. Ordem visual não é ordem lógica

order, row-reverse e column-reverse mudam a apresentação, mas não consertam a sequência da fonte nem, em geral, a navegação sequencial. Se a ordem comunica etapas, prioridade ou leitura, corrija o HTML. Use reordenação visual apenas quando a ordem lógica continuar correta.

Teste obrigatório

Desative o CSS e leia de cima para baixo; depois navegue com Tab. A sequência deve continuar compreensível e o foco não deve saltar contra a ordem visual.

7. Audite o contrato, não a presença de Flexbox

A barra deve preservar a ordem lógica, caber em 320px e deixar a busca usar o espaço restante. Marque somente problemas reais: há três escolhas corretas que não precisam ser removidas.

  1. A barra reverte visualmente itens interativos.
  2. A busca contém uma largura rígida que impede redução.
  3. O link de conta reserva 18rem e não pode encolher.
  4. A barra usa gap: 1rem.
  5. Os itens usam align-items: center.
  6. A conta usa margem inline automática.

8. Corrija tamanho, mínimo e comportamento

O texto longo impede o conteúdo de encolher e o avatar deforma. Mantenha o avatar em 4rem, permita que o conteúdo ocupe o restante, libere seu mínimo inline e quebre a URL. Preserve a ordem do HTML.

9. Aplique ao projeto integrador

  1. use Flexbox somente em grupos cuja relação principal seja uma linha ou coluna;
  2. nomeie os eixos antes de escolher alinhamento;
  3. substitua larguras mágicas por base, crescimento, redução e wrapping justificados;
  4. teste conteúdo longo e decida explicitamente se o mínimo automático deve permanecer;
  5. confirme que ordem visual, leitura sem CSS e navegação por teclado são coerentes.
Entrega da A7

Implemente em styles.css uma navegação e um componente de mídia com Flexbox. Em COMPATIBILIDADE.md, registre para cada um: eixo principal, base dos itens, política de quebra, teste em 320px e teste de ordem com teclado.
