Aula 5 de 22 · 3h · CSS3 — pseudo-classes e pseudo-elementos

Pseudo-classes
e pseudo-elementos

Uma classe escrita no HTML nomeia algo. Uma pseudo-classe seleciona um estado ou uma relação que já existe; um pseudo-elemento seleciona uma parte ou cria uma caixa que não exige marcação extra. Hoje a turma estiliza interação sem esconder foco e acrescenta decoração sem transformar CSS em fonte de conteúdo.

Qual seletor tem especificidade 0–1–1?

  • ::before
  • a:hover
  • :where(a:hover)

1. Um ou dois pontos mudam a pergunta

Pseudo-classe · :

Seleciona o elemento por estado, posição, histórico ou relação.

button:hover { … }
input:checked { … }
li:nth-child(odd) { … }

Pseudo-elemento · ::

Seleciona uma parte do elemento ou uma caixa gerada.

p::first-line { … }
li::marker { … }
.aviso::before { … }

Em CSS moderno, pseudo-elementos usam dois pontos duplos. Navegadores ainda aceitam a forma antiga de um ponto para :before e :after, mas escrever ::before deixa explícito que não estamos selecionando um estado.

2. Interação não é sinônimo de hover

EstadoQuando correspondeCuidado
:hoverO ponteiro designa o elemento.Toque pode não ter hover ou mantê-lo de forma diferente.
:activeDurante a ativação.É momentâneo; não significa “item atual”.
:focusO elemento possui foco.Corresponde independentemente de como o foco chegou.
:focus-visibleO agente entende que o foco deve ser evidenciado.Use para personalizar, nunca para eliminar a indicação.
:focus-withinO elemento ou um descendente possui foco.Útil para destacar um grupo de formulário.
 
.botao:hover { background: #154b57; }
.botao:active { transform: translateY(1px); }
.botao:focus-visible {
  outline: 3px solid #e1a43a;
  outline-offset: 3px;
}
Regra de sobrevivência

Se uma informação ou ação aparece somente em :hover, ela não tem rota garantida por teclado ou toque. Hover pode melhorar uma pista; não pode ser a única porta para a tarefa.

MDN — :focus-visible

Teste: clique, use Tab e mantenha o foco no campo. São três estados diferentes. A borda do grupo vem de :focus-within; o anel do controle vem de :focus-visible.

3. Corrija os estados sem apagar o navegador

O link só parece interativo com mouse e todo foco foi removido. Preserve o estilo de hover, acrescente uma indicação equivalente para teclado e um retorno durante a ativação. Não use outline: none em nenhum estado.

4. Estado estrutural e estado de formulário

Pseudo-classeSelecionaExemplo
:first-childPrimeiro elemento entre irmãos.Retirar a borda inicial de uma lista.
:nth-child(2n)Irmãos nas posições pares.Faixas alternadas em tabela.
:checkedCheckbox ou radio marcado.Destacar a opção escolhida.
:requiredControle com requisito nativo.Indicar campo obrigatório sem classe duplicada.
:user-invalidControle inválido após interação do usuário.Evitar pintar o formulário inteiro antes da tentativa.

:nth-child() conta elementos entre todos os irmãos; o filtro opcional of <selector> pode limitar o conjunto. Não escolha :nth-child por aparência de uma lista que pode receber itens de outro tipo sem conferir a árvore.

Qual seletor acompanha diretamente o estado de um checkbox?

  • .checkbox-clicado
  • input:checked
  • input::checked

5. Pseudo-elemento não substitui conteúdo

::before e ::after criam caixas como primeiro ou último filho do elemento de origem quando content gera algo. São excelentes para decoração. Texto essencial criado apenas no CSS não é confiável: pode desaparecer sem a folha e não é exposto de forma consistente por leitores de tela.

Informação só no CSS

.preco::before {
  content: "Promoção: ";
}

Sem CSS, a condição comercial some do documento.

Conteúdo no HTML, ornamento no CSS

.preco::before {
  content: "";
  inline-size: .6rem;
  block-size: .6rem;
  background: currentColor;
}

A palavra “Promoção” continua no HTML; a caixa é apenas decoração.

6. Audite estados e conteúdo gerado

Pediram: “melhore os estados e reduza HTML desnecessário”. O resultado parece limpo. Marque somente problemas reais; há usos corretos de pseudo-classes e pseudo-elementos.

  1. O link só ganha distinção clara no estado :hover.
  2. A regra de :focus elimina o indicador do navegador.
  3. “Oferta válida hoje” é informação essencial criada apenas por ::before.
  4. Colorir o marcador com li::marker.
  5. Destacar o rótulo com input:checked + label.
  6. Desenhar uma seta decorativa com .botao::after vazio.

7. Decore sem fabricar significado

O CSS inventa os textos “Novo” e “Obrigatório”. Eles são essenciais e já foram colocados no HTML abaixo. Remova os textos de content e use os pseudo-elementos apenas para desenhar uma faixa e um marcador geométrico decorativos.

8. Aplique ao projeto integrador

  1. estilize links e botões em estado normal, hover, active e focus-visible;
  2. use uma pseudo-classe estrutural onde a posição seja realmente o contrato;
  3. use um pseudo-elemento apenas para detalhe que pode desaparecer sem perda;
  4. navegue a home inteira com Tab e registre onde o foco aparece;
  5. desative o CSS e confirme que rótulos, preços e estados essenciais continuam no HTML.
Entrega da A5
