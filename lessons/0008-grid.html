Grid

Grid cria relações explícitas entre linhas e colunas. Hoje a turma define trilhas flexíveis, distingue grade explícita de implícita, posiciona por linhas e áreas sem quebrar a ordem lógica e constrói listagens que respondem ao espaço do contêiner sem adivinhar modelos de aparelho.

Qual necessidade aponta diretamente para Grid?

  • Centralizar um botão dentro de uma linha
  • Alinhar cartões simultaneamente por linhas e colunas
  • Colorir o primeiro item de uma lista

1. Contêiner, itens, linhas, trilhas e células

display: grid transforma os filhos diretos em itens de grade. Linhas numeradas delimitam trilhas; a interseção de uma linha e uma coluna forma uma célula; uma área ocupa uma ou mais células. O conteúdo interno de cada item continua com seu próprio modelo de layout.

TermoSignificado
LinhaLimite numerado ou nomeado entre trilhas.
TrilhaEspaço entre duas linhas adjacentes: uma linha ou coluna.
CélulaInterseção de uma trilha de linha com uma de coluna.
ÁreaRetângulo formado por uma ou mais células.
gapIntervalo entre trilhas, não nas bordas externas.

2. Grade explícita e grade implícita

grid-template-columns e grid-template-rows definem a grade explícita. Quando a colocação ou a quantidade de itens exige outras trilhas, o algoritmo cria grade implícita. Essas trilhas são automáticas por padrão e podem ser controladas com grid-auto-rows e grid-auto-columns.

.galeria {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-auto-rows: minmax(8rem, auto);
  gap: 1rem;
}

Uma altura fixa em linha pode recortar conteúdo ampliado. O par minmax(8rem, auto) estabelece um piso e permite crescimento conforme o conteúdo.

3. Faça as colunas caberem pelo conteúdo

Três colunas fixas de 18rem transbordam no celular. Crie tantas colunas quanto couberem, cada uma com mínimo de 14rem e máximo de uma fração. Garanta que o mínimo nunca seja maior que o próprio contêiner e mantenha gap: 1rem.

4. fr distribui espaço flexível, não ignora conteúdo

A unidade fr representa uma fração do espaço flexível disponível. Uma trilha 1fr possui mínimo automático, frequentemente influenciado por min-content. Conteúdo longo pode fazê-la ultrapassar o contêiner. Quando o contrato permite encolher, minmax(0, 1fr) explicita mínimo zero.

Mínimo automático pode dominar

.layout {
  grid-template-columns: 16rem 1fr;
}

Uma palavra contínua pode alargar a segunda trilha.

Mínimo liberado com intenção

.layout {
  grid-template-columns: 16rem minmax(0, 1fr);
}
main { overflow-wrap: anywhere; }

A trilha pode encolher e o conteúdo ganha quebra.

5. Posicionamento por linhas e áreas

Itens podem ocupar linhas numeradas com grid-column e grid-row, ou áreas nomeadas com grid-template-areas e grid-area. Áreas formam retângulos; repetir um nome em forma de L torna a declaração inválida.

.pagina {
  display: grid;
  grid-template-areas:
    "cabecalho cabecalho"
    "principal lateral"
    "rodape rodape";
  grid-template-columns: minmax(0, 1fr) 16rem;
}

Colocação visual não altera a ordem do documento, da fala nem da navegação sequencial. Estruture o HTML na sequência lógica e use Grid para apresentação, não para consertar significado.

Na presença de espaço para colunas vazias, o que auto-fit faz?

  • Cria sempre exatamente três colunas
  • Recolhe as trilhas vazias e expande as ocupadas
  • Muda a ordem lógica dos itens

6. Alinhe itens e alinhe a grade conscientemente

PropriedadeAlvo
justify-itemsItens dentro de suas áreas no eixo inline.
align-itemsItens dentro de suas áreas no eixo de bloco.
justify-contentA grade inteira quando sobra espaço inline.
align-contentA grade inteira quando sobra espaço no bloco.
place-itemsAtalho para align-items e justify-items.

Alinhamento de itens e distribuição das trilhas não são a mesma operação. Se a grade ocupa todo o contêiner, justify-content pode não produzir mudança visível.

7. Audite trilhas, conteúdo e ordem

O dashboard deve caber em 320px, crescer com o conteúdo e manter a sequência lógica dos três links. Marque somente problemas reais; três escolhas são adequadas e funcionam como decoys.

  1. A grade exige três colunas rígidas de 20rem.
  2. As áreas invertem visualmente a sequência numerada.
  3. O cartão de ações corta conteúdo acima de 8rem.
  4. A grade usa gap: 1rem.
  5. Os cartões são alinhados no início.
  6. O resumo libera seu mínimo inline.

8. Corrija a trilha que não encolhe

A segunda coluna transborda por causa da URL longa. Mantenha a sidebar entre 10rem e 16rem, faça o conteúdo ocupar o restante com mínimo zero e permita quebra em qualquer ponto. Em viewport estreito, a solução deve caber sem largura fixa total.

9. Aplique ao projeto integrador

  1. escolha um conjunto que exija alinhamento real por linhas e colunas;
  2. desenhe linhas e trilhas antes de escrever áreas ou números;
  3. permita que cartões decidam a quebra com auto-fit e minmax();
  4. injete conteúdo longo e revise mínimos intrínsecos;
  5. desative o CSS e use Tab para confirmar que a ordem lógica permanece correta.
